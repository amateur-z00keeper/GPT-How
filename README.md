# GPT-How — Project Path

Beginner-friendly, ADHD-aware project planning website with:

- Guided project intake
- Step-by-step build plans
- Tools, parts, cost, and permit context
- Six assistance levels
- Specialty project agents

The site is a static application prepared for Vercel. Keep `index.html`, `styles.css`, and `app.js` together in the repository root.
